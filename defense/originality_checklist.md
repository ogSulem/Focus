# Чеклист перед проверкой ВКР на заимствования

> Цель: повысить уникальность **законным способом** через качество авторского текста и корректное цитирование.

## 1) Проверка ссылочного аппарата

- [ ] На каждую чужую идею, определение или численное утверждение есть ссылка.
- [ ] В списке источников нет позиций, которые не цитируются в тексте.
- [ ] Формат библиографических ссылок и «дата обращения» единообразен.

## 2) Проверка авторского вклада

- [ ] Разделы по архитектуре, реализации и тестированию описывают именно проект Focus.
- [ ] В тексте есть конкретика по модулям, endpoint-ам, метрикам, сценариям и ограничениям.
- [ ] Выводы сформулированы как результат выполненной работы, а не пересказ учебников.

## 3) Проверка формулировок

- [ ] Нет длинных дословных фрагментов из внешних источников без оформления цитаты.
- [ ] Общие фразы заменены на предметные формулировки по вашему проекту.
- [ ] В каждом разделе есть 1–2 абзаца с интерпретацией результатов «своими словами».

## 4) Проверка приложений и согласованности

- [ ] Все рисунки и таблицы упомянуты в тексте.
- [ ] Нумерация таблиц и рисунков сквозная и без пропусков.
- [ ] Приложения связаны с основной частью явными ссылками.

## 5) Что не делать

- [ ] Не использовать скрытые символы, машинную «перекодировку», подмену алфавитов и иные обходные методы.
- [ ] Не удалять ссылки на источники ради процента уникальности.
- [ ] Не подменять исследовательскую часть «водой» без фактического содержания.

## 6) Финальный прогон

- [ ] Повторно перечитать введение, выводы по разделам и заключение: эти блоки должны быть максимально авторскими.
- [ ] Сверить соответствие «цель → задачи → результаты → подтверждение».
- [ ] Провести финальную проверку в принятой вузом системе и исправить только содержательные замечания.
