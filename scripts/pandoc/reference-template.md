# Шаблон reference.docx для конвертации ВКР Focus

Этот файл нужен только для генерации `reference.docx` с базовыми стилями.

## 1 Заголовок первого уровня

Текст основного абзаца: Times New Roman, межстрочный интервал 1.5, абзацный отступ.

## 1.1 Заголовок второго уровня

Маркированный список:
- пункт 1;
- пункт 2;
- пункт 3.

Нумерованный список:
1. элемент 1;
2. элемент 2;
3. элемент 3.

Таблица 1. Пример табличного блока

| Параметр | Значение |
|---|---|
| Шрифт | Times New Roman |
| Кегль | 14 пт |
| Интервал | 1.5 |

Формула (пример):

$$
E = mc^2
$$

Фрагмент кода:

```ts
function calculateScore(base: number, risk: number): number {
  return Math.max(0, Math.round(base - risk * 10));
}
```
