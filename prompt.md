У меня диплом "интеллектуальная система планирования и анализа продуктивности пользователя". Хочу сделать ахуенный продукт как в топ решениях, вот промпт который мне гпт дал для тебя

🧠 1. Название проекта

Focus — интеллектуальная система планирования и анализа продуктивности пользователя

🎯 2. Цель проекта

Разработка веб-приложения с элементами искусственного интеллекта, предназначенного для:

планирования задач пользователя
анализа продуктивности
формирования персональных рекомендаций по улучшению эффективности работы
🧩 3. Общая архитектура системы
Система состоит из 4 основных модулей:
Frontend (веб-интерфейс)
Backend API
База данных
AI/аналитический модуль

📊 7. Основные функции системы
7.1 Управление задачами (Task System)

Функции:

создание задачи
редактирование задачи
удаление задачи
установка:
title
description
priority (low / medium / high)
deadline
status (todo / in progress / done)
7.2 Аналитика продуктивности

Система должна собирать:

количество выполненных задач
время активности (условное)
распределение задач по дням
Вывод:
график продуктивности по дням
heatmap активности
статистика за неделю/месяц
7.3 AI-аналитика (упрощённая, но эффектная)

Система должна генерировать:

рекомендации пользователю:
“лучшее время для работы: утро”
“низкая продуктивность в вечерние часы”
анализ поведения:
пики активности
периоды прокрастинации

📌 Реализация:

rule-based + простая логика (НЕ обязательно ML)

визуализация прогресса
7.5 Уведомления
напоминания о задачах
уведомления о дедлайнах
(опционально) интеграция Telegram bot
